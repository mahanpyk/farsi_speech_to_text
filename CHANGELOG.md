## 0.1.0

- Recognize Persian speech with the fine-tuned Nemotron streaming model.
- Transcribe mono PCM16 WAV and live 16 kHz PCM16 audio on Android, iOS, Linux, macOS, and Windows.
- Run the same model in a dedicated WebAssembly worker on compatible browsers.
- Download and verify the pinned INT8 weights separately from the app.
- Include a six-platform Flutter demo and an English integration guide.
- Add pull request checks, contribution guidance, dependency updates, and a disabled merge ruleset template.
